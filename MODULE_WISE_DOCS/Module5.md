# Module 5 README: Assembler Compilation and VM Compatibility

## 1. Overview

In Module 5, we focused on building an assembler that:

* Compiles assembly source code into a bytecode file compatible with our VM.
* Ensures the output file produced can be directly processed by the VM parser.
* Tested the assembler end-to-end with the current VM to verify execution correctness.

The goal was to integrate the assembler tightly into the toolchain, making it compatible with both compiler output and VM input.

---

## 2. Implementation Details

### 2.1 Core Work

* **Assembler Compilation:**
  Compiled the assembler source code in a bare shell without any IDE, producing a standalone executable that runs on the host machine.

* **Bytecode Generation:**
  * Translated assembly instructions and directives into a bytecode format readable by the VM.
  * Ensured all constant pool entries, method references, and class metadata are encoded correctly.
  * Output file is structured to allow direct parsing by the VM without modification.

### 2.2 VM Compatibility

* Verified that the assembler output works seamlessly with the current VM by running the code.

### 2.3 Testing and Verification

* Checked that constants, method calls, class definitions, and labels were correctly resolved.
* Measured input and output file sizes to ensure efficiency and storage optimization.
